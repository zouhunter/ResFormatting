# Resource Formatting (Unity)

##### Unity资源导入格式设定

### 功能
- 配置图片/音效/FBX等模板
- 命名规则匹配工程资源
- 资源格式批量修改
- 资源导入时自动格式化


### 快速使用
1. 配置新规则:Window/ResFormatting/New FormatRule
2. 可视化查看影响的资源:Window/ResFormatting/FormatView
